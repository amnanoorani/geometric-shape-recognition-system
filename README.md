# Geometric Shape Recognition System

## Description
A computer vision shape detection tool that identifies circles, squares, and triangles from input images.

## Tech Stack
Python, OpenCV, NumPy

## Features
- Shape detection through contour analysis and edge detection
- Classifies circles, squares, and triangles from input images
- Achieved ~90% classification accuracy
- Demonstrates how image processing translates visual data into mathematical rules
